# Чек-лист сборки и производства (SY156-A510)

Что сделать на **каждом новом планшете** перед выдачей аппарата. Подробности —
по ссылкам. Секреты (PIN, токены, коды привязки) в протоколы не записывать.

## Облако и спецификация

- [ ] Запись облачных данных и пуско-наладка — `docs/provisioning.md`,
  «Последовательность на заводе».

## Панель навигации

- [ ] Выставить `persist.sys.statusbar=hide` и применить:

  ```
  adb shell 'su 0 setprop persist.sys.statusbar hide; am broadcast -a com.teamhd.action.UPDDATE_STATUSBAR'
  ```

- [ ] Проверить: `adb shell getprop persist.sys.statusbar` → `hide`;
  `adb shell 'dumpsys window | grep -c "Window #.*NavigationBar"'` → `0`.

Свойство хранится **на каждом планшете отдельно** (не в приложении и не в
облаке) и переживает перезагрузку. Сброс до заводских, скорее всего, его
стирает — после сброса проверить снова. Почему `hide` и что видно с `show` —
`docs/kiosk_device_owner.md`, «Панель навигации на SY156-A510».
