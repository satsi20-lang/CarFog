# Киоск через Device Owner и Lock Task (эксперимент, ветка device-owner-spike)

Проверено на старом тестовом планшете rk3568 (Android 13, userdebug),
версии 1.10.4+32…+35, 11.10.2026. На SY156-A510 (CARFOG-100) **не
проверялось** — см. раздел «Не проверено».

Старый киоск через HOME-алиас (тумблер «Киоск-режим», `docs/kiosk_mode.md`)
остаётся как был. Всё описанное ниже работает только после назначения
Device Owner; без него вкладка показывает «Device Owner не назначен», кнопки
неактивны, приложение ведёт себя как раньше.

## Что это даёт

Device Owner — роль «владелец устройства»: приложению разрешено управлять
системными политиками. Lock Task — закрепление экрана за одним приложением.

Вместе, при включённой блокировке:

* шторка (свайп сверху) не открывается — строка состояния отключена;
* навигация не работает: Home, «Недавние» и меню питания (долгое нажатие)
  не выводят из приложения; свайп снизу показывает только неактивную
  кнопку «Назад»;
* роль домашнего экрана закреплена за приложением политикой и переживает
  обновление APK;
* после обновления и после перезагрузки приложение поднимается само и
  снова закрепляет экран — без касаний.

Короткое нажатие питания по-прежнему гасит экран — это не выход из
приложения.

## Условия

1. На планшете **нет аккаунтов** (`adb shell dumpsys account` → `Accounts: 0`).
2. **Один пользователь** (`adb shell pm list users` → только `0:Owner`).
3. Device Owner ещё не назначен (`adb shell dumpsys device_policy` — нет
   строки `Device Owner:`).
4. Установлена версия с приёмником `CarfogAdminReceiver` (1.10.4+32 и новее
   из этой ветки).

Если аккаунт или второй пользователь есть — назначение откажет; помогает
только сброс до заводских.

## Как назначить

1. Подключиться к планшету по adb.
2. Выполнить:

   ```
   adb shell dpm set-device-owner ee.carfog.dryfog/com.example.dry_fog_app.CarfogAdminReceiver
   ```

   Ответ при успехе: `Success: Device owner set to package ee.carfog.dryfog/...`.
3. Проверить: `adb shell dumpsys device_policy | grep -A2 "Device Owner"` —
   там `admin=ComponentInfo{ee.carfog.dryfog/com.example.dry_fog_app.CarfogAdminReceiver}`.

`ee.carfog.dryfog` — идентификатор приложения, `com.example.dry_fog_app` —
пакет классов (namespace); они разные, команда должна содержать оба именно
так.

## Как включить и выключить блокировку

1. Сервисное меню (долгое нажатие в левом верхнем углу заставки или экрана
   «Временно не работает», PIN) → вкладка «Киоск».
2. Раздел «Device Owner (Lock Task)» → переключатель «Блокировка включена».
3. Включение сохраняется и применяется при каждом старте приложения.
   Выключение снимает закрепление, возвращает шторку и навигацию, роль
   домашнего экрана возвращается к тумблеру «Киоск-режим».

## Три кнопки техника (там же, за PIN)

1. **«Выйти из блокировки на 10 минут»** — закрепление снято, шторка и
   навигация работают. Через 10 минут блокировка возвращается сама
   (таймер не зависит от того, что открыто на экране). Если приложение за
   это время перезапустилось — блокировка включается сразу.
2. **«Открыть настройки на 10 минут»** — то же, плюс сразу открываются
   системные настройки (например, включить беспроводную отладку). Через 10
   минут приложение само выходит на передний план и закрепляет экран.
3. **«Снять Device Owner»** — два подтверждения. Снимает закрепление, все
   политики киоска и саму роль Device Owner. Приложение остаётся на экране
   (через ~1 с поднимается заново — сервисное меню закрывается, экран
   начинается с выбора языка). Назначить снова — только командой из раздела
   «Как назначить».

Каждое включение, выход, снятие и ошибка пишутся в журнал приложения (тег
`Kiosk`), без PIN и токенов.

## Аварийный выход без приложения (root)

Нужен, если приложение не открывается или PIN недоступен, а планшет
закреплён. Требуется adb и root (`su`). Проверено на rk3568.

Пути без root **не работают**:

* `dpm remove-active-admin …` → `SecurityException: Attempt to remove
  non-test admin`;
* `am task lock stop` → закрепление остаётся;
* `am force-stop ee.carfog.dryfog` → Android не останавливает приложение —
  владельца устройства.

Последовательность:

1. Удалить файлы политик устройства:

   ```
   adb shell "su 0 rm /data/system/device_owner_2.xml /data/system/device_policies.xml"
   ```

2. Перезагрузить: `adb reboot`.
   После загрузки Device Owner нет, закрепления нет, шторка и навигация
   работают. Приложение всё ещё открывается кнопкой «Домой» (роль
   домашнего экрана хранится отдельно от политик).
3. Если беспроводная отладка выключилась после перезагрузки — включить её
   в «Настройки → Для разработчиков» (теперь доступны).
4. Вернуть системный рабочий стол:

   ```
   adb shell "su 0 pm disable ee.carfog.dryfog/com.example.dry_fog_app.KioskHomeAlias"
   ```

   Без `su` команда отказывает (`Shell cannot change component state`).
5. Проверить: `adb shell dumpsys device_policy` — нет `Device Owner:`,
   `Enabled Device Admins` пуст.

Что не трогается: данные приложения (настройки, журнал, мастер-код) и
системные настройки — проверено сравнением до и после. Признак «блокировка
включена» в приложении сохраняется: если позже снова назначить Device Owner,
блокировка включится при первом же появлении приложения на экране.

## Обновление APK

1. Android при замене пакета убивает процесс и возвращает HOME-алиас в
   состояние из манифеста (выключен).
2. Приложение ловит `MY_PACKAGE_REPLACED`: восстанавливает алиас и
   политики и само запускается (Device Owner вправе запускать экран из
   фона).
3. Экран снова закреплён примерно через 2 с после замены пакета
   (замеры: 1,8 и 1,9 с), интерфейс — ещё через ~4 с. Device Owner,
   отключённая шторка и роль домашнего экрана сохраняются без повторной
   настройки.

## Перезагрузка

1. Система сама запускает приложение как домашний экран (~1 с после
   окончания загрузки).
2. Приложение закрепляет экран ещё через 1–1,5 с. Чёрного экрана на
   rk3568 не было.
3. Беспроводная отладка Android после перезагрузки выключается — включать
   через «Открыть настройки на 10 минут».

## Как снять Device Owner

Обычный путь — кнопка «Снять Device Owner» (см. выше). Аварийный — через
root (см. выше). Сброс до заводских тоже снимает, но стирает всё.

## Ограничения

* Назначить Device Owner можно только на планшете без аккаунтов и с одним
  пользователем; иначе — сброс до заводских.
* Без root аварийного выхода нет: если приложение не открывается и PIN
  потерян, остаётся только сброс до заводских.
* Во время временного выхода кнопка «Назад» закрывает экран приложения,
  «Домой» сразу поднимает его снова (короткое мигание).
* При снятии Device Owner или выключении блокировки экран приложения
  пересоздаётся (если он был поднят как домашний экран): ~1 с, сервисное
  меню закрывается. Если процесс приложения умрёт в эту секунду, Device
  Owner останется назначенным при выключенной блокировке — кнопку можно
  нажать ещё раз.

## Не проверено на SY156-A510 (CARFOG-100)

1. Вендорская шторка: закрывают ли её `setStatusBarDisabled` и Lock Task.
2. Чёрный экран при тёплой перезагрузке — на rk3568 его не было, но там
   нет шины и другая прошивка.
3. Назначение Device Owner на обычное (не системное) приложение
   `ee.carfog.dryfog` на этой прошивке.
4. Тихая установка через Тулбокс: приходит ли `MY_PACKAGE_REPLACED` и
   поднимается ли приложение так же, как после `adb install -r`.
5. Настоящий портретный экран: на rk3568 портрет эмулировался
   `wm size 800x1280`.
6. Аварийный выход через root — пути к файлам политик могут отличаться.
